2. Resolve blocking issues by identifying the blocking session and investigating the queries involved, rerouting or optimizing them as necessary.
3. Consider temporarily increasing CPU resources or redistributing workloads during peak usage times.
4. Enable query store to help track performance issues over time and identify trends.

**Prevention Recommendations:**

- Regularly review and optimize indexes and update statistics to improve query performance.
- Set up and automate alerts for high CPU usage and blocking sessions to proactively address potential issues.
- Implement regular performance tuning sessions to analyze query performance and application behavior in response to database load.
- Review application query designs to ensure they are optimized for performance, particularly under high load scenarios.
